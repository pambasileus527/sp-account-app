# ビデオとブラウザ

ホームの「ビデオ」「ブラウザ」は、メール・設定と同じく、ほかとは別のアプリです。ログイン中のときだけ開けます。

## ビデオ（`/video`）

- 動画の検索は、サーバー（`GET /api/video/search?q=`）がYouTube Data API v3 を呼びます。画面からYouTubeを直接呼びません（キーを見せないため）。
- 検索語が空のときは、いま人気の動画（日本）を出します。
- 同じ検索は10分間まとめて、YouTubeの1日の利用枠を節約します。1人あたり1分に30回までの回数制限もあります。
- 再生は、YouTube公式の埋め込みプレーヤー（`youtube-nocookie.com`）だけです。ダウンロード、広告の除去、音声だけの取り出し、プレーヤーの見た目の改変は、規約で禁止されているので作りません。
- CSPは、サムネイルの `https://i.ytimg.com` と、埋め込みの `https://www.youtube-nocookie.com` だけを外から許可しています。

### キーの設定

1. Google Cloud Console で、YouTube Data API v3 を有効にして、APIキーを作る。
2. キーの「APIの制限」を YouTube Data API v3 だけにする。
3. `.env` に `YOUTUBE_API_KEY=...` を書いて、`docker compose up -d`。

キーが空のあいだは、5本のサンプルを表示します（画面に「サンプルを表示しています」と出ます）。サンプルは再生できません。

## ブラウザ（`/browser`）

Googleの検索欄だけの画面です。Googleは、ほかのページの中に埋め込めないので、検索すると別のウィンドウで開きます。開けるサイトを制限する機能は、まだありません。
